# Safari-style New Tab для Firefox

Расширение заменяет новую вкладку и домашнюю страницу Firefox на страницу с поисковой строкой и сеткой закладок в стиле Safari:

- показывает содержимое **«Меню закладок»** (Bookmarks Menu) с папками любой вложенности;
- папка открывается во всплывающем окне, вложенные папки открываются в нём же, есть кнопка «назад» и хлебные крошки;
- закладки всегда актуальны: страница читает их через `browser.bookmarks` и перерисовывается при любом изменении;
- поиск идёт через поисковую систему, выбранную в Firefox по умолчанию, а адрес вида `github.com` открывается напрямую;
- иконки сайтов загружаются с `icons.duckduckgo.com`, если иконки нет, показывается цветная плитка с буквой.

## Проверка без подписи (временная установка)

1. Откройте `about:debugging#/runtime/this-firefox`.
2. Нажмите «Load Temporary Add-on…» и выберите `manifest.json`.
3. Откройте новую вкладку.

Временное расширение удаляется после перезапуска Firefox.

## Постоянная установка (подпись через AMO, без публикации)

1. Войдите на https://addons.mozilla.org → Developer Hub → **Manage API Keys** и создайте ключ (JWT issuer + JWT secret).
2. Подпишите расширение:
   ```sh
   npx web-ext sign --channel=unlisted \
     --api-key=<JWT issuer> --api-secret=<JWT secret>
   ```
   Подписанный `.xpi` появится в `web-ext-artifacts/`.
3. `about:addons` → ⚙ → **Install Add-on From File…** → выберите `.xpi`.
4. Когда Firefox спросит про изменение новой вкладки или домашней страницы, выберите «Сохранить изменения».

Обновление: поднимите `version` в `manifest.json` и снова выполните шаг 2.

## Известные ограничения

- На новой вкладке Firefox сначала ставит фокус в адресную строку, и расширение не может это изменить. Чтобы начать печатать в поле поиска на странице, кликните по нему или нажмите Tab.
- Иконки берутся у внешнего сервиса, поэтому DuckDuckGo видит домены ваших закладок.
